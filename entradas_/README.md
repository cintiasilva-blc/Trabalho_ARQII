# Arquivos de entrada

Esta pasta contém os arquivos utilizados nos experimentos.

## Matrizes

As matrizes de dimensões 256×256, 512×512 e 1024×1024 são geradas utilizando o código `matriz/gerador.c`, disponibilizado pela professora.

Para gerar os arquivos, execute na raiz do projeto:

```bash
make
cd entradas
../matriz/gerador
cd ..
```
